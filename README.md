# Ashen Oath client updates

Generated from the tested pack lock files. Minecraft 1.20.1 / Forge 47.4.10 / Java 17.
The feed is `feed/pack.toml`. Enable GitHub Pages with source **GitHub Actions**.
Publish only tested releases to main. Clients check the feed before launching.

Managed: locked mods, resource packs, gameplay scripts, quests and required game configuration.
Preserved: options.txt, Punchy profiles and personal client configuration (packwiz preserve=true).
Saves, account files, server addresses and live logs are never published.
Additional personal files are not managed or removed by the updater.
Minecraft/Forge upgrades require a separate Prism component update.
Third-party downloads retain their original source URLs; only bundled pack files are hosted here.
